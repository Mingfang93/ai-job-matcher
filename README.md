# AI Job Matcher

A Python-based job description analyzer designed to identify technical skills in recruitment advertisements.

## Project Overview

This personal learning project explores how Python and, in future versions, Large Language Models (LLMs) can support job requirement analysis.

## Current Features

- Keyword-based skill detection in job descriptions
- Case-insensitive text matching
- Identification of skills mentioned or not mentioned in a job description

## Technologies

- Python
- String processing
- Lists, loops, and conditional statements

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run the following command:

`python3 main.py`

## Example Output

```text
=== AI Job Matcher ===
Found: Python
Found: LLM
Found: SQL
Not found: Java
```
